# BooKKeeper
A CLI-tool for personal accounting

Идея такая: мы пишем команду, она выдает в консоли доходы / расходы / статистику за указанный период / красивую схему статистики / таблицу доходов и расходов

Схема таблицы:
Доходы                             [дата]          [дата]          [итого]
    Работа
    Аванс
    Премия
    Подарки
    Кэшбэк
    Дивиденды
Расходы
    Коммуналка
    Связь
    Интернет
    Кредит
    Базовые продукты
    Кафе
    Одежда
    Развлечения
    Здоровье
    Штрафы
    Отпуск
    Ремонт
Остаток
